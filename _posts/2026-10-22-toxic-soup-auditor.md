`toxic-soup-auditor` 是一个判断中文文案是不是毒鸡汤的 Agent Skill。给它一段励志文案、人生哲理或朋友圈金句，它会拆出这段话到底许诺了什么，分清是祝愿、信仰、比喻、反讽还是字面劝告，再按伪因果、美化苦难、宿命论、道德绑架、绝对化、现实损害六个维度打分，告诉你算不算毒鸡汤、哪句越了界、合理的部分在哪，最后给一句不带虚假保证的改写。

它不会见到「吃苦」「因果」「上天」就批。「愿你苦尽甘来」是祝愿，「我信善有善报」是在讲自己的信念，这类话它会判成基本合理。文末放了完整的 Skill 文件，Claude Code、Codex 等支持 Skill 的 Agent 都能直接装。

## 它怎么判断一段话

整个流程五步，批量输入时每段单独过一遍，不先给整篇定性再往下套。

1. **拆主张。** 每段拆成三层：安慰或价值（「珍惜父母」）、事实或因果（「受苦必有福」）、行为导向（「所以不用维权」）。原文没写出来的行为导向只能标「潜在推论」，不能说成原文主张。
2. **先看语境。** 「接受无法改变的事」不等于劝人放弃能改变的事；拿「福报」挖苦加班文化的反讽，也不是在宣扬福报。没有上下文时按字面理解，并写明「按字面理解」。
3. **六维打分。** 每个维度 0～2 分，总分 0～12。
4. **双向论证。** 每段都要说清合理内核在哪、从哪一步跳到了误导、现实里该怎么说。
5. **输出和改写。** 按用户要的粒度出结果，最后给改写。

六个维度是这样分工的：

| 维度 | 看什么 |
|---|---|
| A 伪因果 | 因果或补偿机制本身有没有根据，比如报应转移、前世债、上天偿还 |
| B 美化苦难 | 把痛苦说成好事，或说成受害者自己的错 |
| C 宿命论 | 劝人放弃改变、求助、离开或维权 |
| D 道德绑架 | 用孝道、感恩、善良要求一方无条件忍让 |
| E 绝对化 | 「必然」「一定」「只要……就」 |
| F 现实损害 | 场景涉及就医、维权、人身安全、财务时，照做的后果有多严重 |

0～2 分算基本合理，3～5 分是混合表达，6 分以上是明显的毒鸡汤风险。Skill 里反复强调，这只是审读用的启发式量表，不是心理测量工具，也不许写成「毒鸡汤概率 75%」。

我觉得这个 Skill 最值得看的是防误伤那一半。「不该判成毒鸡汤的情况」写得和该判的一样细：纯祝愿、非强制的宗教表达、文学和悼词、局部成立的经验、反讽，各有例子，还配了五种复查方法。比如去修辞测试，就是把金句改写成普通陈述，看还剩不剩事实许诺。要是你只想要一个见鸡汤就批的工具，它会显得啰嗦，那就不适合你。

## 分析一句话的结果

拿「你现在受的苦都是福报，熬过去老天一定加倍还你。」按默认模式走一遍，结果如下。分数是我按 rubric 一条条对出来的，可以拿后面的评分准则复核。

```text
结论：混合表达（按字面理解，A1 B1 C1 D0 E2 F0，共 5 分）

1. 「受的苦都是福报」把眼下的苦一律说成好事，没区分哪些苦能避免、哪些该及时止损（B）。
2. 「老天一定加倍还你」用「一定」许诺了一个没法验证的补偿（E）；「受苦换回报」这个机制本身也没有根据，但原句没拿它指导具体决定（A 记 1）。
3. 「熬过去」只给了等这一条路，没提能做什么（C）。

合理内核：想告诉对方难处不会一直这样，给人撑下去的劲。

改写：现在确实难，但这种日子往往不会一直持续。先看看哪些事能找人帮忙、哪些可以先放一放，一步一步来。
```

这句话没有落在明显风险区，因为它没劝人放弃什么具体行动。可要是说给一个正在被家暴或被长期欠薪的人听，F 维会升到 2，C 维也会跟着升，总分就过了 6。

## 几条规则为什么这样写

**同一种表述只计一个维度。** 「一定」既像伪因果，又像绝对化。要是 A、E 两个维度都给分，一个词就是 4 分，「只要足够孝顺，上天一定会补偿你」这种句子会被推到明显风险的边上。所以 rubric 开头有一张计分规则表：确定措辞只计 E，A 只看机制本身有没有根据；劝人放弃只计 C，F 只看场景后果；把痛苦说成好事计 B，要求忍让牺牲计 D。按这个规则，那句孝顺得 A1、D1、E2，共 4 分，算混合表达。

**打分前先读 rubric。** SKILL.md 里那张维度表只说每个维度看什么，没写 0、1、2 分各对应什么样的句子，只凭它打分容易飘。逐条审查、深度审查和 JSON 模式都要先读 rubric；默认模式只要一个结论，拿不准时再读就行。

**反讽单独处理。** 「只要加班到猝死，老板就会感动，真是福报啊」字面是鸡汤，实际在骂鸡汤。语气明显时按反讽读，只有分不清是反讽还是宣教时才标「语境不足」。

**紧急情况先给求助建议。** 用户说自己或身边的人正面临暴力、自伤、急病时，先建议报警、打急救电话或联系专业机构，再分析文本。

**测试集和标定案例不用同一批句子。** 标定案例是给 Agent 读的，用来校准尺度；测试集是给你检验用的。两边要是同一批句子，Agent 等于读过答案再做题，判对了也说明不了什么。这里 17 条测试和标定案例里的句子互不重复，最难判的混合表达放了 4 条。

装好以后直接说就行，不用点名 Skill，`description` 里写了「这是不是毒鸡汤」「逐条判定」「理性改写」这些触发词。几种常见说法：


```text

```

```text

```

```text

```

只问一句是不是，它给结论、两三条理由和一句改写；贴一串编号文案，它出逐条表格，挑风险最高的几条细讲。

```markdown
# 毒鸡汤辨析（Toxic Soup Auditor）

## 目标与边界

识别**表面提供安慰或激励，实际可能扭曲因果、消解行动力或正当化伤害**的表述；不是检测“积极文案是不是坏文案”，也不是检验宗教信仰或作者人格。

- 主要分析**论证与潜在行动后果**，不以“提到上天、因果、吃苦、放下”直接判为毒鸡汤。
- 区分：事实/因果断言、价值主张、情绪支持、比喻/诗性语言、信仰内部表达、反讽。对模糊语境给出条件性结论。
- 不推断作者真实意图、读者心理状态，不给无根据的「AI 生成概率」「洗脑概率」等统计数字。
- 保留合理内核；避免把现实中无法确保的结果表述成必然结果。
- 不假装有外部验证；涉及现实医学、法律、金融、历史等可核查事实且用户需要核实时，使用可用检索工具并引用来源；否则只做文本逻辑评估。
- 用户说明自己或身边的人正面临暴力、自伤、急病等紧急危险时，先建议报警、拨打急救电话、联系可信任的人或专业机构，再做文本分析。

## 触发时的默认行为

用户提供一段或多段文本并询问是否属于毒鸡汤、哪些话具有误导性、文案如何更理性，执行本技能。无需追问用途即可先给判断。

根据指令选择输出粒度：

1. **默认（短文本或单句）**：结论 + 2～4 条具体理由 + 合理内核 + 一句理性改写。
2. **逐条审查（多段、编号文本）**：逐条归类的 Markdown 表格 + 高风险句详析 + 汇总 + 可行动的替代表述；保留原编号。
3. **深度审查**：每段给六维评分、语境与反例、现实风险、改写。
4. **仅改写**：不大段说教，直接给不增加虚假保证的文本；按用户希望的温柔/犀利/简洁风格改写。
5. **JSON 模式**：用户明确要求结构化输出时，采用 [输出模板](assets/report-template.md) 的字段约定。

逐条审查、深度审查和 JSON 模式打分前先读取 [评分准则](references/rubric.md)；默认模式可按下文的维度表判断，拿不准时再读。

## 审查流程

按顺序执行；批量输入时，每段独立分析，**不要先定整篇立场再套用**。

### 1. 提取主张

对每段记录一句最能代表其推论的短引文，并将其拆成：

- **安慰/价值层**：例如「善待自己」「珍惜父母」。
- **事实/因果层**：例如「受苦必有福」「害你的人会替你受灾」。
- **行为导向层**：例如「因此无需维权」「只需等待上天安排」；没有明确出现时标注「潜在推论」，不要说成原文主张。

### 2. 先检查语境，防止误伤

确认它是字面劝告、宗教信念、文学隐喻、反讽，还是只是一句表达情绪的诗句。无上下文时，以通常读者可能作出的字面理解评估，并写明「按字面理解」。语气明显是反讽时（如用「真是福报啊」讽刺加班文化）按反讽读并写明；只有分不清是反讽还是宣教时，才标「语境不足」。

反例：

- 「愿你苦尽甘来」是祝愿，**不是**保证所有人受苦就会发财。
- 「接受无法改变的事」不等于「放弃改变能改变的事」。
- 「我相信善有善报」描述信念，本身不等于诱导放弃维权。

### 3. 六维风险评分（每维 0～2）

总分 0～12：

| 维度 | 要辨识的风险 |
| --- | --- |
| A 伪因果/不可验证机制 | 因果或补偿机制本身没有根据，如报应转移、前世债、上天偿还 |
| B 美化苦难/归责受害者 | 把痛苦或伤害说成好事，或说成受害者自己的过错 |
| C 宿命论/消解行动 | 劝人放弃可行的改变、求助、退出或争取权益 |
| D 道德绑架/单向牺牲 | 用孝道、善良、感恩、坚强等要求一方无条件忍让 |
| E 绝对化/虚假承诺 | 用“必然、一定、只要……就……”跨越现实条件 |
| F 现实损害风险 | 所在场景涉及就医、维权、人身安全、反诈骗、重大财务决策，照做后果严重 |

**同一个问题只计一次**：「必然、一定、只要……就」这类措辞只计 E，A 只看机制本身有没有根据；明确劝人放弃行动只计 C，F 只看所在场景的后果有多严重；把痛苦说成好事计 B，要求一方忍让牺牲计 D。

默认阈值：**0～2 基本合理/非典型毒鸡汤；3～5 混合表达/部分毒鸡汤；6～12 明显毒鸡汤风险**。这是一套**审读启发式量表，不是经验证的心理测量工具**；应允许说明具体理由高于机械分数。对于模糊隐喻可给「语境不足，按字面暂评」。

> 如果没有可指认的主张或风险，不要仅凭悲观、宗教、古风、积极或网络流行语提高分数。发现明显的 F 维现实风险时，即使总分不高，也在结论中提示。

### 4. 做「双向论证」

每段至少提出：

1. **合理内核**：对方可能想表达什么，在哪些条件下成立。
2. **误导跳跃**：从「什么可能有帮助」跳到「什么必然发生」，或从个人选择跳到对所有人的要求。
3. **现实替代**：把不可验证承诺改成可执行且有边界的建议。

引用必须能对应原文；没有写出的意思仅称「可能引申为」，不冒充原句。

### 5. 输出判断，并给改写

表格列按 [输出模板](assets/report-template.md)：「编号」「判断」「原文依据」「风险点」「合理内核」。逐条分析后突出分数最高或最有现实后果的 2～4 段，每段给一句更理性的改写。

整篇总结写明四类各有几条（明显毒鸡汤风险、混合表达、基本合理、语境不足）及判定依据。不因高风险条目多，就断定所有段落都无价值；不因含暖心句子，就淡化具体误导。

## 改写守则

- 保留原文核心情绪（安慰、积极、珍惜关系），但删除「苦难必获福报」「作恶必遭病灾」「一切天注定」一类无根据的肯定句。
- 用「可能、往往、在……条件下、值得、可以尝试」替代不合理的「一定、必然」。不是机械替换，应说明现实限制。
- 将「你要忍」「等报应」改为「识别事实、设定边界、采取行动」。
- 医疗、法律、暴力等高风险场景优先强调专业支持和及时处理；不要让鸡汤代替治疗或安全计划。

## 质检清单

完成前自查：①每条有可定位的文本证据；②同时识别合理内核；③分清隐喻、反讽和字面；④同一问题没有在多个维度重复计分，评分与结论不矛盾；⑤不编造科学证据；⑥不以宗教身份做负面推断；⑦理性改写具体可用；⑧如用户仅要结论则简洁。

需要标定案例时读取 [标定案例](references/calibration-examples.md)。
```

### references/rubric.md

```markdown
# 详细评分准则与误判控制

此量表用于一致性讨论，**不是经过临床或学术验证的诊断量表**。评分针对「该文本在当前语境下作为人生建议被采信时的误导风险」，不是作者是否善良、读者是否脆弱，也不是宗教真伪判断。

## 计分规则：同一个问题只计一次

六个维度各管一件事，同一处表述不要在两个维度重复拿分：

| 表述 | 只计在 | 不计在 |
| --- | --- | --- |
| 「必、一定、只要……就」等确定措辞 | E | A |
| 因果或补偿机制本身没有根据 | A | E |
| 明确劝人别求助、别维权、别离开 | C | F |
| 场景涉及就医、维权、安全、财务的后果严重度 | F | C |
| 把痛苦或伤害说成好事、说成受害者的错 | B | D |
| 要求一方忍让、牺牲、服从 | D | B |

## 维度评分锚点

### A. 伪因果/不可验证机制（0—2）

只看因果或补偿机制本身有没有根据，措辞是否绝对交给 E。

- **0**：没有事实性因果断言；或明确标注为信念/祝愿；或因果关系现实可观察。
- **1**：暗示一种缺乏根据的联系（如美德换回报、吃苦换富贵），但没有据此给出具体的现实判断。
- **2**：宣称不可证实的因果或补偿机制（如报应转移、前世债、上天偿还），并据此给出现实判断或行动建议（如「欠钱的人会替你挡灾，所以不用催」）。

### B. 美化苦难/归责受害者（0—2）

- **0**：承认痛苦和选择权，强调自护。
- **1**：将吃苦普遍化为磨炼，可能忽视适用条件。
- **2**：直接称严重伤害是「福」、必需或受害者应偿还的「债」，使伤害正当化。

### C. 宿命论/消解行动（0—2）

- **0**：安慰与行动并存，鼓励做能做的事。
- **1**：有消极等待倾向，但不明示放弃行动。
- **2**：明显劝人放弃可行选择、求助、维权或离开危险环境。

### D. 道德绑架/单向牺牲（0—2）

- **0**：尊重当事人意愿与能力边界。
- **1**：以「应该」普遍倡导某种美德，忽略现实差异。
- **2**：用羞耻、孝道、感恩或责任迫使一方长期单向牺牲，否定拒绝权。

### E. 绝对化/虚假承诺（0—2）

- **0**：承认不确定性和条件。
- **1**：明显夸张或概括（如「所有」「每次」「总没错」），但不会明显误导重要选择。
- **2**：以「必、一定、只要就」许诺不可保证的结果或报应。

### F. 现实损害风险（0—2）

只看所在场景照做后果有多严重；原文有没有明说「别去」交给 C。

- **0**：即使照做，基本不会妨碍判断与自护。
- **1**：可能推迟止损、减少求助、强化自责；潜在、间接。
- **2**：所给语境涉及治疗、维权、人身安全、反诈骗或重大财务决策，照做可能造成明显损害。

注意：F 评分依赖上下文。单纯文学句子不能凭空推演成「鼓励被虐待者继续忍受」。如果用户明确说用于劝慰正在遭受家暴的人，F 评分就可能显著增高。

## 总分与标签

- **0—2：基本合理／非典型毒鸡汤**。可标注有瑕疵，尽量不贴重标签。
- **3—5：混合表达／部分毒鸡汤**。承认合理安慰，同时清楚指出逻辑跳跃。
- **6—12：明显毒鸡汤风险**。指出误导是如何发生的，以及更安全的替代做法。
- **语境不足：暂不定性**。适用于只有三四个字的名言、分不清在讽刺还是宣教、只截到半句话时。可按字面给临时分，但不强行做最终定性。语气明显是反讽时按反讽评分，不归入此类。

分数只是组织证据的工具，**不得写成「毒鸡汤概率 75%」**。如果分数和直观结论出现明显矛盾，先按上面的计分规则复查是否重复计分，或假设了原文没有出现的行为后果；必要时阐明条件性结论。

## 典型论证模式

- **苦难神圣化**：「吃苦」→「注定获得回报」。忽略苦难的无效性和可避免性。
- **道德补偿幻觉**：「我善良」→「上天欠我的必归还」。将价值取向伪装成因果保证。
- **超自然替代正义**：「欺负你的人会遭殃」→「不用再维护权利」。后一句若没写出，只称潜在诱导。
- **责任转嫁**：「对方伤害了你」→「是你前世欠债」。混淆谁对实际行为负责。
- **宿命卸责**：「某些事不能控制」→「没有任何必要采取行动」。前件未必推出后件。
- **非黑即白**：「不够吃苦」→「一定一生艰辛」。忽视条件、资源和机遇差异。

## 不应判成毒鸡汤的情况

1. **纯祝愿**：「愿你平安，苦尽甘来。」不是对未来的事实保证。
2. **非强制的宗教表达**：「在我的信仰里，善有善报。」可讨论其信念背景，但不能单凭超自然词汇判定高风险。
3. **切实可用的提醒**：「遇到无法改变的事，接受情绪；能够改变的部分，逐步行动。」
4. **文学/悼词/歌词**：主要服务于情感表达，不能自动当政策建议阅读。
5. **局部成立的经验**：「规律训练通常有助于提高技能。」即使有修辞性夸张也不必重罚。
6. **反讽**：「又被裁员了，真是满满的福报。」字面是鸡汤，实际在讽刺鸡汤。

## 对抗误判的复查方法

- **去修辞测试**：把金句改成普通陈述。如果去掉押韵比喻后没有事实许诺，避免过度批判。
- **行动测试**：读者按建议行动，是否减少正当求助、退出、维权或治疗？仅推测的风险要标「可能」。
- **极端场景测试**：若发生家暴、欠薪、严重疾病等，是否仍然适用？不适用说明需要加条件，不代表原句在所有场景都恶意。
- **反例测试**：只需一个容易想象的现实反例就能打破「一定」论证；这不等于证实相反命题「永远不会」。
- **慈善解释测试**：先给原话最合理的一种理解，再辨识越界之处，避免稻草人。
```

```markdown
# 标定案例与讲解

目标：帮助使用者输出稳定、不过度苛刻的分析。下列「预期」是建议区间/类别，实际文本和语境可能改变得分。

| 示例句 | 预期类别 | 理由 |
|---|---|---|
| 「父母健在是福，要常回家看看，孝顺积德就会得福报。」 | 混合表达 | 珍惜父母是合理内核；「孝顺必换福报」属于额外的交换式因果，具体强度依语境判断。 |
| 「孩子要多吃苦，不然将来必定一辈子穷。」 | 混合表达 | 训练韧性有价值，但穷富不由吃苦单独决定，存在绝对化与道德压力。 |
| 「别整天胡思乱想，能改变的努力做，不能改变的试着放下。」 | 基本合理 | 尊重行动力和不确定性。 |
| 「你承受的所有伤害都是上天赐的福，不要抗拒。」 | 明显风险 | 美化伤害，并可能压制退出、求助与维权。 |
| 「能一起走一段路就值得珍惜，走散也不必否定过去。」 | 基本合理 | 情绪安慰，不作事实保证。 |
| 「以前执着的东西如今不想要了，允许自己改变。」 | 基本合理 | 允许价值变化，不替别人设定义务。 |
| 「骗过你的人一定会替你生病，你无需追责。」 | 明显风险 | 无依据的惩罚转移 + 明示放弃追责。 |
| 「只要你善良，天迟早会把你失去的钱加倍还给你。」 | 明显风险 | 虚假必然补偿，可能妨碍经济决策和止损。 |
| 「别长期纠结不值得的事，但涉及权益时记得处理证据和时效。」 | 基本合理 | 情绪调节与行动兼容。 |
| 「伴侣伤害你，是因为你上辈子欠他，忍过就还清了。」 | 明显风险 | 前世债务叙事转移现实责任，正当化受伤害。 |
| 「愿你苦尽甘来。」 | 基本合理 | 纯祝愿，不是必然因果。 |
| 「我信善有善报，这能让我更愿意善待人。」 | 基本合理 | 个体信仰经验，没有许诺他人一定有回报。 |
| 「我不能确定未来是否会更好，但现在可以先解决眼前的问题。」 | 基本合理 | 不夸大确定性，保留可行动建议。 |
| 「人生皆有因果。」 | 语境不足 | 可能是宗教命题、文学表达、行为心理学隐喻，不能据此推断是否有害。 |
| 「领导对你苛刻是为了成就你，无论如何不要离职。」 | 明显风险 | 将权力不对等美化为培养，否定退出权。 |
| 「努力不一定成功，但能帮助你获得更多选择。」 | 基本合理 | 既不否定行动，也不许诺成功。 |
| 「工资拖了三个月，老板说这是在培养我们的格局，真是感动。」 | 基本合理（按反讽读） | 语气明显在讽刺老板的说法，本身不劝人忍受欠薪。 |

## 计分示例

「只要足够孝顺，上天一定会补偿你。」按计分规则拆开：

- A 1：「孝顺换补偿」的机制没有根据，但没据此给出具体决定。
- D 1：普遍倡导孝顺，没要求长期单向牺牲。
- E 2：「只要……一定」许诺不可保证的结果。
- B、C、F 均为 0。

总分 4，混合表达。「一定」只在 E 计分，不给 A 加到 2。

这些案例只用于校准尺度。评分必须重新读取完整输入，不得因为出现相似关键词就机械复制标签。
```
